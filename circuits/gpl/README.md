# circuits/gpl — GPL-3.0

Everything in this directory derives from iden3's circomlib or circomlibjs, which
are GPL-3.0, and is distributed under the GPL-3.0 as well (see [LICENSE](./LICENSE)).
The rest of the repository is Apache-2.0.

| File | Derived from | What changed |
| --- | --- | --- |
| `transfer.circom` | includes `poseidon.circom` | The ownership circuit itself (docs/CIRCUIT.md) |
| `poseidon.circom` | circomlib 2.0.5 `circuits/poseidon.circom` | One `include` line: BLS12-381 constants instead of BN254 |
| `poseidon_constants_bls12381.circom` | circomlib's `poseidon_constants.circom` format, values from iden3's optimizer | Generated by `../poseidon/build.mjs`; do not edit |
| `optimize.mjs` | circomlibjs 0.1.7 `tools/poseidon_optimize_constants.js` | Field, input and output are arguments instead of bn128 and fixed paths |
| `poseidon.ts` | circomlibjs 0.1.7 `src/poseidon_reference.js` | BLS12-381 field and constants; permutation unchanged |

`poseidon.ts` is imported by the command-line tools (`scripts/prove.ts` through
`scripts/lib/zk.ts`), so the prover, as a program, combines Apache-2.0 files with
GPL-3.0 ones and is distributed under the GPL-3.0's terms. The web application
imports nothing from here; `npm run build && npm run zk:check-bundle` checks that.
